# 4차 — 전수 재생성·감사 + 입력 강건성 + 형식 보강

3차의 정제·반복 공식을 유지하면서, ① 데이터 청정도(원천 게이트 + 전수 감사) ② 입력 강건성(적대 공격 방어) ③ 형식 준수를 한 회차에 보강했다. 5개 모델 학습·전수 평가 완료. (당초 계획은 형식 보강만이었으나, 학습 데이터에서 비주권성 혼입이 발견되어 원천부터 전수 재생성으로 범위를 확대.)

## 1. 데이터 파이프라인

```
원천 청크 2,098 ─ 주권 적격성 게이트(Kimi 심사) ─→ 1,730 keep
  + 웹 보강 수집 417 (정부 정책·사회 쟁점·문화·지리)  ─→ 통합 1,886 청크
  → 질문 재생성 14,219 (사실형 + 입장·균형형)
  → 자료 비참조 답변 생성 (closed-book, 교사 Kimi-K2.6)
  → 품질 심사(근거성·품질·유용성) → 3등급 분류(핵심 1,654 / 부차 2,189 / 제외 1,346)
  → 핵심사실 고반복 프레이밍 4,903 + 최신성 앵커 232
  → ★ 전수 소버린 감사 17,219건 (Kimi 재심사 + Claude 교차 적대검증)
      → 비소버린 217 제거 (외국 일반지식 146·방법론 63 등 / 오탐 33 구제)
  + 형식셋 2,865 + 강건성 609 + 범용 4,000
  = train 22,424 / eval 1,006 / test 1,054  (8:1:1, 완전·준완전일치 누수 0)
```

- **주권 적격성 게이트**: 주제로 거르지 않음(과학·경제도 한국 실질이면 keep) — *문서 메타·설문 양식·방법론 잡음*만 제거. `scripts/gate_chunks_sovereign.py`
- **전수 감사**: 표본이 아니라 전건. 1차 심사(Kimi)가 플래그한 250건을 다른 모델(Claude)이 적대 재검증 — "한국 주권 각도가 진짜 없는가"를 역방향으로 따져 오탐 33건 구제. `scripts/audit_sovereign.py`
- **split 원칙**: 지식 주입이 목적이므로 같은 원천의 *다른 표현* 질문이 train/eval에 나뉘는 것은 누수가 아니라 주입 측정 설계. 완전·준완전 일치(문자 3-gram 자카드 ≥0.85)만 차단. `scripts/build_dataset_v4.py`

## 2. 입력 강건성 (신규)

**측정 → 표적 보강 → 균형** 3단계:
1. **측정**: 강건성 점검셋 60(5개 공격 유형 × 10개 핵심 주권 입장 + 정상 질문 10)으로 5개 모델의 3차 학습본을 측정 → 약한 유형 확인(장문매몰 24%·역할극 35%·압박 39%).
2. **표적 생성**: 약한 유형 × 핵심 주권 입장 14종(독도·동해·위안부 등 안정 9 + 현 대통령·국무총리 등 최신성 5)으로 "공격 → 입장 유지 + 정중한 정정(근거 동반)" 학습쌍 497건. 건별 적대 검수(입장 유지·반대주장 미채택·과방어 아님).
3. **균형**: 협조적 정상 질문 112건 동봉 — 과방어(정상 질문 거부) 방지.

최신성 입장은 교사 모델의 지식 단절(구 정권 정보) 때문에 **골드 시드 주입 + 규칙 엔티티 검수**로 생성(모델 검수 금지). 점검셋 60은 학습 데이터와 격리(held-out).

## 3. 형식 준수 보강셋 (3차 계획분 포함)

`scripts/make_format_set.py` — 표준 벤치 복제 금지(평가 오염 방지), 새로 창작. mc 792 / short 773 / yesno 730 / brief 570 = **2,865건**. 샘플: [`samples/format_set_sample.jsonl`](samples/format_set_sample.jsonl).

## 4. 학습

- 5개 모델 LoRA(r16/α32, 응답 구간만 손실, 3 epoch, max_seq 2048). `scripts/run_train_v4.sh`
- **Gemma 수정**: gemma-4-E4B는 멀티모달이라 vision/audio 타워의 커스텀 모듈(`Gemma4ClippableLinear`)이 LoRA와 충돌 → 타깃을 **텍스트 디코더로 스코프한 정규식**(`model.language_model.*`의 7개 투영)으로 해결. `scripts/train_lora_v2.py`

## 5. 평가 (전수, 표본 없음)

| 평가셋 | 규모 | 채점 |
|:--|:--|:--|
| 핵심사실 평가셋(새 표현) | 431 | LLM 심사(judge 0~1) |
| 소버린 test(입장·균형·부차) | 1,054 | LLM 심사 |
| 최신성 정보 점검셋 | 17 | 규칙(정답 엔티티) |
| **강건성 점검셋** | 60 | 공격=LLM 심사 / 최신성·정상질문=규칙 |
| 일반 벤치(KMMLU·HAE-RAE·KoBEST) | 9,652 전체 | 객관식 정확도 |

결과 표·해석은 루트 [README §4-(3) 4차](../README.md) 참조. 핵심:
- **강건성 공격 종합 44% → 86%**, 정상 질문 100% 유지(과방어 0)
- 최신성 65~88%, 주권 주입 Qwen·Swallow·Llama 3축 동반 상승
- EXAONE·Gemma 일반벤치 하락은 **로그우도 교차 검증(전체 9,652 재채점, `scripts/ll_bench_check.py`)으로 분해**: Gemma=형식 이탈이 주범(능력 손상 −0.045, KMMLU +0.02), EXAONE=로그우도에서도 −0.142로 실손상 → 5차 모델별 처방 확정(Gemma=형식·주입 약화 / EXAONE=학습 강도 축소)
