# 4차 — 형식 준수 보강 (verbose 드리프트 교정)

## 배경 (3차 진단)
3차에서 주권 사실·입장 주입은 성공했으나, closed-book 추론형(CoT) 학습으로 답변이 **장황해져 객관식 단답 형식을 이탈**(일반벤치 strict↓·미응답률↑). 지식은 유지됨 — 즉 *지식 망각이 아닌 형식 이탈*.

## 처방
- **데이터**: v3.1 학습셋(주권 주입 자산) **그대로 유지** + **형식 준수 보강셋** 추가. → 짧게 물으면 짧게, 설명하라면 설명하는 *형식-따르기*를 재학습(무조건 단답화 아님).
- **설정(데이터 아님)**: Gemma는 3차의 전 모듈(all-linear) 적응이 출력 스타일을 과적응시킴 → **타깃 모듈(q/k/v/o) LoRA**로 교정.
- 평가셋은 3차 것(`핵심사실 평가셋`·`최신성 정보 점검셋`·일반벤치) 재사용 — 동일 기준 비교.

## 형식 준수 보강셋
`make_format_set.py` — 교사모델(Kimi)로 한국어 형식-따르기 예시 생성. **표준 벤치(KMMLU·KoBEST·HAE-RAE) 복제 금지**(평가 오염 방지, 새로 창작).

| 유형 | 지시 | 답 형식 |
|:--|:--|:--|
| mc | "정답만 한 글자로(A/B/C/D)" | 글자 1개 |
| short | "한 단어로만" | 한 단어 |
| yesno | "예 또는 아니오로만" | 예/아니오 |
| brief | "한 문장으로 간단히" | 1문장 |

생성 **2,865건** (mc 792 / short 773 / yesno 730 / brief 570). 주제: 일반상식·과학·기초 한국문화·생활 등 20종. 샘플: [`samples/format_set_sample.jsonl`](samples/format_set_sample.jsonl).

## 4차 학습셋
`build_v4_mix.py` — `train_v4 = v3.1(14,884) + 형식셋(2,865) = 17,749`. eval/test는 3차 것 재사용.

## 상태
데이터 생성·조립 완료. **학습 대기**(5종 LoRA, Gemma만 타깃 모듈) → 학습 후 3차 평가셋으로 재측정(형식 이탈 회복 + 주권 주입 유지 확인).
