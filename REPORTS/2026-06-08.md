# 2026-06-08 · K-SOVA 3차

> **요약** — 1차·2차 학습 데이터를 비교해 사실 정확성 정체의 원인을 규명(반복 부족 + 회상 불가한 지엽 사실 과다). 이를 근거로 데이터를 정제·반복 강화하여 3차 학습셋(14,884건)을 완성하고 품질을 검증함. 학습은 자원 가용 시 착수.

## 1. 시도
"1차는 사실 정확성이 향상(0.70→0.87)되었는데 2차는 왜 정체(0.22~0.31)되었나"를 학습 데이터 수준에서 비교 분석.

## 2. 원인 규명
- **1차**: 75개 핵심 쟁점을 각 약 30회, 다양한 표현으로 반복 → 암기 성공.
- **2차**: 약 2,400개의 서로 다른 사실을 각 2회 정도만 노출 + 회상이 불가능한 정밀·일회성 세부사실이 다수 → 암기 실패와 환각.
- **결론**: 사실 정확성은 핵심 사실을 충분히 반복하고 회상 가능한 종류일 때만 오른다.

## 3. 조치: 3차 데이터 정제
- 사실형 문항 5,649개를 세 기준(주권 중요도·회상 가능성·정확성 필수 여부)으로 분류 → **핵심 보존 1,122 / 원리형 유지 2,306 / 제거 2,221**.
- 회상 불가한 지엽 사실 2,221개 제거(환각 원인 제거).
- 핵심 사실은 다양한 표현으로 반복 강화 — 사실당 약 9회, 현 국가체제 사실(현직 대통령 등)은 25~55회. (반복 문항 간 표현 중복도 낮음)
- **품질 검증**: 생성된 반복 문항의 사실 충실성을 모델로 전수 심사 → 92% 통과, 부적합 324개 제거.
  - 단, 현 국가체제 사실은 심사 모델의 지식이 시점상 뒤처져 정답을 오판하므로(예: 현직 대통령) **규칙 기반으로 별도 검수**.

## 4. 결과물
- 3차 학습셋 14,884건. 핵심 보존 사실의 반복량이 1,122 → 5,079로 증가.
- 검증셋은 핵심 사실의 반복 문항이 섞이지 않도록 분리(평가 오염 방지).

## 5. 다음 계획
- 자원 가용 시 5개 모델 학습 → 자체 지식 점검 문항 40개 + 초기 75개 주권 쟁점 평가셋으로 주입 여부 확인.
- 이후 강건성 2단계(입력 강건성) 진단용 평가 문항 60개와 측정 절차를 사전 준비 완료.

## 6. 교훈
지식 주입은 사실당 충분한 반복과 다양한 표현이 필수다. 또한 학습 시점 이후의 현재 사실은 교사 모델로 검수할 수 없으므로 규칙 기반 검수가 필요하다.
