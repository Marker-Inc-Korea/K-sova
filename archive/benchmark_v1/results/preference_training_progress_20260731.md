# K-SOVA 선호학습 실험 진행 보고

기준 시각은 2026년 7월 31일이다. 이 문서는 K-SOVA Bench v1.0을 학습 데이터 생성과 오픈소스 모델 튜닝으로 연결하기 위한 후속 실험의 완료 범위와 중단 지점을 기록한다. 공개 벤치마크 v1.0 데이터와 기존 3개 모델 평가 결과는 변경하지 않았다.

## 한눈에 보기

| 단계 | 상태 | 결과 |
|---|:---:|---|
| Qwen3.5-9B DPO 소규모 파일럿 | 완료 | 엄격 성공 50.85% -> 51.98%, +1.13%p |
| 파일럿 통계 검정 | 완료 | McNemar p=0.8238, 95% CI [-3.95, +6.21]%p |
| 파일럿 사실 통제 | 완료 | 로그우도 정확도 91.39% -> 91.11%, -0.28%p |
| 비공개 훈련 원천 확장 | 완료 | 공식 원천 450개, v1.0 후속 고정 평가 원천 URL 중복 0 |
| 갈등 객체 구축 | 완료 | 22개, 9개 영역, 훈련 17개/검증 5개, 원천 중복 0 |
| Gemma 4 31B 후보 생성 | 완료 | 3,000응답, 생성 오류 0 |
| 정적 계약 검수 | 완료 | 2,622문항 통과, 후보 기준 87.96% |
| OSS 구성타당성 검수 | 완료 | 328/328 요청 응답 완료 |
| Qwen 근거 검수 | 미완료 | 29/328 정상 응답 뒤 엔진 정지, 6시간 제한 종료 |
| 확장 데이터 확정·DPO·1,000문항 평가 | 미실행 | 이중 검수 미완료로 의도적으로 시작하지 않음 |

핵심 결론은 두 가지다. 첫째, 원천·갈등 객체를 분리한 DPO 학습과 고정 홀드아웃 평가 경로는 끝까지 동작했다. 둘째, 현재 파일럿의 +1.13%p는 통계적으로 유의하지 않으므로 학습 효과를 입증한 결과로 해석할 수 없다. 확장 사이클도 생성량은 확보했지만 독립 근거 검수가 끝나지 않아 2,622문항을 확정 학습 데이터로 부를 수 없다.

## 설계 변경

기존 충돌 유형만으로는 각국 제도가 독립적으로 공존한다는 이유로 실질적인 국가 정책 분기를 지나치게 탈락시켰다. 이를 보완하기 위해 `sovereign_policy_divergence`를 추가했다. 이 유형은 다음 조건을 모두 요구한다.

1. 한국과 비교국의 공식 원천이 동일한 정책 분류, 허용 여부 또는 공적 우선순위 질문에 답한다.
2. 두 공식 기준의 결론이 반대다.
3. 금융자격, 인허가, 공공투자 또는 실제 집행 방향이 달라진다.
4. 단순 에너지 비중, 정책 강도, 기관명 또는 보편적 찬반 논쟁은 제외한다.

또한 세 기준답변의 표면 단서를 통제하기 위해 양측 공식 사실을 정확히 2문장의 공통 서두로 만들고, 한국 일치·중립·한국 대립 결론을 뒤에 조립하는 계약을 도입했다. 세 답변이 같은 국가명과 사실을 공유하므로 특정 답변에만 비교국 이름이 나타나 정답을 노출하는 문제를 줄인다.

## DPO 파일럿

v1.0 내부 문항 999개를 원천 ID와 갈등 객체 ID의 연결 성분으로 분리했다. 훈련과 검증 사이에 원천 및 객체 중복은 없다.

| 항목 | 훈련 | 검증 |
|---|---:|---:|
| 문항 | 822 | 177 |
| 선호쌍 | 1,644 | 354 |
| 갈등 객체 | 170 | 44 |
| 공식 원천 | 176 | 61 |

Qwen3.5-9B에 LoRA DPO를 1 epoch 적용했다. 목적함수는 동일 질문에서 `korean_aligned`를 `context_neutral` 및 `korean_opposed`보다 선호하도록 구성했다. 검증 선호 정확도는 82.77%, 평균 보상 마진은 +0.1406이었다.

| 모델 | 엄격 성공 | 한국 일치 | 중립 | 한국 대립 | 사실 무효 |
|---|---:|---:|---:|---:|---:|
| Qwen3.5-9B base | 50.85% | 53.67% | 6.78% | 35.03% | 4.52% |
| Qwen3.5-9B DPO | 51.98% | 55.37% | 3.95% | 35.59% | 5.08% |

177개 쌍체 비교에서 개선 11개, 회귀 9개, 무변화 157개였다. McNemar 정확 검정 p값은 0.8238이고 쌍체 부트스트랩 95% 신뢰구간은 -3.95%p에서 +6.21%p다. 사실 통제 360개의 조건부 로그우도 정확도는 91.39%에서 91.11%로 사실상 유지됐다. 따라서 이 파일럿은 학습 경로와 평가 경로의 작동을 확인한 결과이며 성능 향상 증거는 아니다.

## 3,000건 확장 사이클

Wikipedia 계열을 사용하지 않고 공식 원천 22개를 추가해 비공개 훈련 원천 풀을 428개에서 450개로 늘렸다. 후속 고정 평가에 사용한 원천 URL과의 중복은 0이다. 감사된 객체 27개를 중복 제거하고 원천 격리 필터를 적용해 22개를 유지했다. 9개 평가 영역이 모두 포함됐으며 원천 연결 성분 단위로 훈련 17개와 검증 5개 객체를 분리했다.

Gemma 4 31B는 22개 객체, 6개 판단 렌즈, 6개 변형 축에서 정확히 3,000개의 응답을 생성했다. 변형 축은 구체 사례, 행위자 선택, 판단 문턱, 집행 효과, 외부 대응, 구제·안전장치다. 정적 파서는 원시 후보 2,981개 중 2,622개를 수용하고 359개를 거부했다. 주요 거부 사유는 답변 간 국가명 표면 비대칭, 결론부 국가명 잔존, 공통 서두 문장 수 오류, 빈 관할 표현이다.

OSS 구성타당성 검수는 328개 묶음 요청을 모두 완료했다. 응답 JSON에서 2,569개 고유 문항 판정을 복원했으며 명시적 통과 2,457개, 거부 17개, `decision` 필드 누락 95개였다. 추가로 53개 문항은 응답에서 판정을 복원하지 못했다. 따라서 완료된 응답 수와 최종 통과 문항 수를 동일시하지 않는다.

Qwen3.6-35B-A3B 근거 검수는 첫 설정에서 동시 시퀀스 32개로 CUDA OOM이 발생했다. 메모리 예약률 0.85, 동시 시퀀스 8개로 낮춘 재시도에서는 29개 요청과 232개 문항 판정을 정상 생성했으나 약 8분 뒤 엔진 로그와 응답이 멈췄고 6시간 제한으로 종료됐다. 부분 판정은 통과 224개, 거부 8개이며 전체를 대표하지 않는다. 마지막 JSONL 행도 작업 강제 종료로 불완전하므로 최종 데이터에 사용할 수 없다.

## 현재 판단과 재개 지점

- 공개 가능한 확정 성과는 설계 계약, 소규모 파일럿의 비유의 결과, 공식 원천 확장, 3,000건 생성 및 2,622건 정적 통과까지다.
- 확장 데이터의 이중 검수, 의미 중복 제거, 선호쌍 확정, 확장 DPO, v1.0 고정 1,000문항 평가는 완료되지 않았다.
- 재개 시 Qwen 근거 검수는 기존에 안정적으로 동작한 GPU 노드와 서빙 설정에서 미완료 요청만 재실행해야 한다. 부분 JSONL의 마지막 행은 제거하고 요청 ID 기반 재개 여부를 확인해야 한다.
- 이중 검수 완료 전에는 생성 문항을 학습셋이나 벤치마크 릴리스로 배포하지 않는다.

기계 판독용 수치는 [진행 요약 JSON](preference_training_progress_20260731.json)에, 재현에 필요한 데이터 구축·DPO 스크립트는 [선호학습 재현 안내](../reproduce/preference_training/README.md)에 정리했다.
