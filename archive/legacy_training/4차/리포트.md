# K-SOVA 4차 — 전수 재생성·감사 + 입력 강건성 + 형식 보강

## 1. 목적

영토(독도·동해)·역사 주권·헌법·현 국가체제 등 한국의 주권적 사실과 입장을 모델에 내재화한다. 답변은 **외부 자료를 참조하지 않고**(자료 비참조 방식) 모델 자신의 지식으로 설명하게 하여, 출처를 지어내는 인용 환각을 방지한다.

4차에서는 3차에서 확립한 주권 주입 위에 세 가지를 추가로 확보하는 것을 목표로 한다. ① 학습 데이터를 **원천부터 전수 재생성**하고 전건을 감사하여 데이터 청정도를 높이고, ② 적대적 입력에 흔들리지 않는 **입력 강건성**을 주입하며, ③ 답변 **형식 준수**를 보강한다.

## 2. 데이터

### (1) 데이터 유형
학습 데이터는 답변의 성격에 따라 3가지 유형으로 생성한다.
- **사실형(fact)**: 객관적·검증 가능한 주권 사실(독도 영유권의 역사적 근거, 발해의 역사 귀속, 헌법상 영토 범위 등). 주권 중요도·회상 가능성에 따라 **핵심사실**(고반복 주입)과 **부차사실**(저빈도)로 등급화하고, 회상 불가능한 일회성 정밀 사실은 **제외**한다.
- **입장형(stance)**: 한국 정부·학계의 공식 입장(동해 표기, 위안부 동원의 강제성, 강제동원·식민지배의 불법성 등).
- **균형형(balance)**: 대립 쟁점에서 양측 논거를 함께 제시하되 한국 입장의 근거를 분명히 한다.

위 3유형을 9개 분야(법령·역사·정치·지리·언어·사회·경제·교육·문화) × 최신성(시점 의존 사실 — 현 대통령·헌재소장·정부조직 등) 위에서 생성한다.

### (2) 4차 생성 — 전수 재생성·감사 + 입력 강건성 + 형식 보강
3차 대비 변경은 3가지 + 형식셋이다.

1. **원천부터 전수 재생성**: 원천 청크에 '주권 적격성 게이트'(교사 모델 심사 — 주제가 아니라 *문서 메타·방법론 잡음*만 제거)를 적용하고, 웹 보강 수집(정부 정책·사회 쟁점·문화·지리 417건)을 더해 → 질문 14,219개를 재생성 → 자료 비참조 답변 작성 → 품질 심사 → 3등급(핵심사실·부차사실·제외) 분류.
2. **학습셋 전수 소버린 감사**: 17,219건 전건을 교사 모델이 재심사하고, 별도 모델로 교차 적대검증 → 비소버린(외국 일반지식·조사방법론·문서 메타) **217건 제거**, 오탐 33건 구제.
3. **입력 강건성 데이터 609건(신규)**: 5개 모델을 강건성 점검셋으로 측정해 약한 공격 유형(장문 매몰 24%·역할극 35%·압박 39%)을 확인 → *약한 유형 × 핵심 주권 입장 14종(안정 9 + 최신성 5)*으로 "공격 → 입장 유지 + 정중한 정정" 학습쌍을 생성·적대검수(적대 497 + 협조 112 — 과방어 방지 균형). 최신성 입장은 교사 모델 지식 단절 문제로 골드 시드 + 규칙 검수.
4. **형식 준수 보강셋 2,865건**(3차 계획분) 포함.

### (3) 생성 규칙·검수
- **자료 비참조**: 답변에 "~에 따르면" 등 출처 인용을 쓰지 않음(인용 환각 방지).
- **핵심 사실 반복 주입**: 중요한 사실은 직접 질문·시기·맥락·외국인 관점·구어체·오답 교정 등 다양한 표현으로 반복.
- **지엽적 사실 제외**: 한 번만 등장하는 정밀·일회성 세부사실은 회상이 불가능하므로 제외.
- **생성·검수**: 교사 모델(Kimi-K2.6)이 질의응답을 생성 → ① 규칙 기반 자동 검수 ② 모델 기반 품질 심사를 거쳐 채택.

### (4) 학습셋 분할
train **22,424** / eval **1,006** / test **1,054** (8:1:1, 질문 단위 층화, 완전·준완전 일치 누수 0).

## 3. 학습 방법

- **사용 모델**: 한국어 능력을 갖춘 5개 공개 모델을 학습 대상으로 한다.
  - EXAONE-3.5-7.8B-Instruct (LG AI Research)
  - Qwen3.5-9B (Alibaba)
  - Llama-3.1-8B-Instruct (Meta)
  - Llama-3.1-Swallow-8B-Instruct-v0.3 (Swallow, 일본어 강화 Llama)
  - gemma-4-E4B-it (Google Gemma 4)
  - 학습 데이터 생성 교사 모델은 **Kimi-K2.6**.
- **학습 설정**: 저랭크 적응(LoRA) 미세조정, 응답 구간만 손실 계산, 3 epoch. (일반 한국어 데이터를 일부 혼합해 일반 능력 유지)
- **Gemma 특수 처리**: 멀티모달 모듈 충돌을 해결한 **텍스트 디코더 타깃 LoRA**로 교정 시도.

## 5. 함의

- **입력 강건성(③)이 4차 최대 성과**: 강건성 데이터 609건만으로 공격 방어가 전 모델에서 급등(종합 44→86%)했고 정상 질문 회피는 0이었다. *측정 먼저(약점 확인) → 표적 보강 → 협조 균형 동봉* 설계가 작동했음을 보여준다.
- **최신성(②)**: 65~88%로, 골드 앵커 고반복이 안정적으로 작동했다.
- **주권 주입(①)**: Qwen·Swallow·Llama 세 축이 동반 상승했다(주권 입장 정렬 +0.19~0.24). EXAONE은 원래 한국어가 강해 보합이었다.
- **망각(④)**: 표준 로그우도(lm-eval-harness) 기준 전 모델 하락이 작다(−0.005~−0.063). 특히 **Swallow는 −0.005로 거의 완전 보존**되었고, Qwen −0.035·Gemma −0.038도 미미하다. 특정 모델만 심각하게 손상되지는 않는다.
- 데이터 청정도(전수 감사)와 입력 강건성을 함께 확보하면, 적은 분량의 표적 보강으로도 방어 성능을 크게 끌어올리면서 일반 능력 손실은 작게 유지할 수 있다.

## 6. 한계

- **Gemma의 주입 역효과 지속**: 타깃 모듈(텍스트 디코더 LoRA)로 바꿔도 주권 품질이 역효과를 보였다(−0.03~−0.14). 모듈 범위가 아니라 *학습 강도* 문제로 결론지었다 — 기준 점수가 5종 중 최고라 학습이 덮어쓰기로 작동한 것이다.
- **EXAONE은 보합에 그침**: 원래 한국어가 강해 주권 주입 효과가 미미했다.
- **일반 벤치 손실의 모델 편차**: EXAONE(−0.057)·Llama(−0.063)는 다른 모델보다 하락이 상대적으로 컸다(다만 보통 수준).
- 입력 강건성 중 **장문 매몰 유형**은 일부 모델(EXAONE 30%)에서 학습 후에도 여전히 약했다.
