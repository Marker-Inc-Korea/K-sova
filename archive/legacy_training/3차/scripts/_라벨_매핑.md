# 사실형 3등급 — 코드 라벨 ↔ 보고서 용어

| 코드(`bucket`) | 보고서 용어 | 뜻 |
|---|---|---|
| `CORE` | 핵심사실 | 반드시 암기·환각 불가 (독도·헌재 판례·5·18·최신성 정보). 고반복 주입 |
| `SECONDARY` | 부차사실 | 원리 수준 보조 사실. 그대로 유지 |
| `EXCLUDE` | 제외사실 | 회상 불가한 지엽·일회성. 학습서 제거 |

- **최신성 정보**: 시점 따라 변하는 현 국가체제 사실(현 대통령·헌재소장·여야 구도 등). 핵심사실 중 시간 변동분.
- 이 3등급 분류는 **3차 작업**(2차 사실 진단 → 분류 → 정제). 1·2차엔 등급 개념 없음.
