## 보존 및 제외

질문 480개·생성 요청 480개·문항 계약 480개·쟁점 계약 250개는 바이트 그대로 복사했다. 추가 학습 모델 두 종만 결과에서 제거하고 남겨 둔 2,880개 문항별 결과는 원래 레코드 바이트를 유지했다. 모델별·영역별·유형별·기준별·생성 진단 표에서도 같은 6개 모델만 남겼다.

학습 데이터, 학습 스크립트, LoRA 체크포인트, 학습 전후 비교, 이후 다른 데이터셋, 내부 실행 로그·인증정보를 포함하지 않았다. 모델 응답 전문과 전체 judge 요청·원출력은 기존 공개 정책에서 제외된 자료다. 따라서 이 공개본은 문항·계약·범주 판정·집계를 검토할 수 있지만 원응답을 통한 판정 재검토에는 한계가 있다.

출처 정보 330개는 같은 commit의 `data/current/sources.jsonl`에서 정확한 source_id로 연결하고 제목·URL·기록 시각·원문 해시 등 메타데이터만 추출했다. 제3자 원문과 장문 발췌는 재배포하지 않는다. 출처 제목이나 정부 발행 사실만으로 모든 reference 문장이 입증됐다고 표시하지 않는다.

## 코드의 계보

`tools/scoring_logic.py`의 프롬프트·schema·산식 함수는 공개 commit의 `gpt54mini_itemwise_judge.py`에서 원문 그대로 추출했다. 집계 함수도 공개 집계 코드에서 그대로 추출했다. 별도 생성한 준비·재현·파일검증 도구는 이번 공개 정리 코드다.

공개 commit의 구현과 저장 점수의 산식 일치는 확인한다. 그러나 당시 실행한 바이너리·모든 세션의 코드 해시까지 복구했다는 주장은 하지 않는다. 원평가 manifest의 내부 입력 해시는 `results/evaluation_summary.json`의 `source_run_input_hashes`에 출처로 보존하며 해당 내부 원파일까지 배포하는 것은 아니다.

기존 `anchor_accuracy=1.0` 등은 **원래 8개 모델 실행에 기록된 진단 값**으로 남겼다. 이번에 6개 모델로 새 보정 시험을 했다는 뜻도, 사람 판정과 일치율 100%라는 뜻도 아니다.
