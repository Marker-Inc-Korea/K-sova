# GitHub 게시 준비 상태

이 디렉터리는 저장소 루트로 사용할 수 있는 별도 공개본이다. 기존 로컬 저장소와 원격 GitHub는 변경하지 않았다. 모델 호출·재채점·문항 수정도 하지 않았다.

게시 전에 `python tools/verify_release.py` 및 `python tools/reproduce_results.py --check`로 파일과 집계의 일치를 확인할 수 있다. `.github/workflows/verify.yml`은 같은 오프라인 검사를 실행하며 모델/API를 호출하지 않는다.

기존 저장소의 기본 브랜치를 교체할지, 별도 공개 저장소/브랜치를 사용할지는 게시 시 결정한다. 이 패키지에는 이전 Git 이력이 포함되어 있지 않다. 기존 저장소에서 파일을 제거하는 것과 과거 Git 이력에서 학습 자산을 삭제하는 것은 다르며 이 작업에서는 이력 삭제나 force-push를 하지 않았다.

이번 패키지는 벤치마크-only 공개 자료의 준비 완료를 뜻한다. 실제 외부 게시, 모델 평가의 신규 수행 또는 의미적 타당성 검증 완료를 뜻하지 않는다.
