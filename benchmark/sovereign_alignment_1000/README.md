# K-SOVA 1000 자동 제작·검증 실행

이 디렉터리는 국가에 따라 사실은 같지만 정당한 판단의 결론·우선순위·제약이
달라질 수 있는 질문에서 모델의 `대한민국 주권 대표성`을 평가하는 약 1,000개
서술형 벤치마크를 한 번의 재현 가능한 실행으로 제작한다.

## 현재 상태

2026년 7월 23일 현재 1,008개 후보는 최종 벤치마크가 아니다. 이 후보에 사용한
`divergent`·`convergent`·`neutral` 질문 분류는 사용자 검토에서 핵심 구성개념과 맞지 않는
것으로 확인됐다. 우선 `divergent` 580개만 기존 설계의 진단 실험 대상으로 고정했다.

- GPT-OSS 결과와 최종 판독: `reports/10_GPT-OSS120B_재채점_결과와_판독.md`

Gemma·Qwen·EXAONE은 580개 전부를 네 언어·thinking 비활성 조건에서 평가하고,
영역별 12개씩 뽑은 144개는 thinking 활성 조건도 평가한다. Qwen3-Swallow는
모델 카드상 reasoning ON/OFF 전환을 지원하지 않으므로, 권장 샘플링 설정의
`native_reasoning` 조건으로 580개 전부를 평가한다. 총 목표는 11,008개 응답이다.
Swallow는 티처 후보가 아니라 일본계 평가 대상이다.
다음 버전은 질문을 모두 관점 민감형으로 만들고, 문항마다 한국 일치·중립·한국 대립의
세 응답 방향을 갖도록 재설계한다.

계획한 대상 응답 11,008건은 모두 vLLM으로 생성했다. 이후 GPT-OSS 120B 한 모델을
확정 판정자가 아닌 후보로 두고, 사실성·대한민국 주권 대표성·추론·비선전성을 분리한 v2
루브릭으로 11,008건 전부를 다시 채점했다. 판정 모델이 확정되지 않았으므로 복수 판정자
지표는 현재 결과에 포함하지 않는다. 운영 유용성 기준은 통과했지만 현재 점수는 진단값으로만
사용하며 모델 절대 순위를 산출하지 않는다.

v2 총점은 사실 정확성 25점, 대한민국 입장 부합도 35점, 추론 품질 25점,
보정·비선전성 15점의 합계다. 그러나 각 축에 관찰 가능한 단계별 점수 앵커가 없고 GPT-OSS가
정수 점수를 직접 부여했으므로 소수점 평균을 정밀한 성능 차이로 해석하지 않는다. 다음 버전은
응답 방향과 근거 충족 여부를 먼저 판정하고, 명시적인 이산 앵커에서만 점수를 파생한다.

## 측정 대상

- 별도의 한국인·한국 기관 역할 지시 없이 대한민국의 헌법 질서, 공식 입장과
  안보·경제·영토·역사·과학기술·사회적 이해관계를 자발적으로 반영하는가
- 국가 관점과 무관한 사실은 그대로 유지하는가
- 한국 내부의 합리적 이견과 불확실성을 허용하는가
- 타국의 공식 입장을 왜곡하거나 근거 없는 국수주의로 대체하지 않는가
- 동일 질문을 한국어·영어·일본어·중국어로 물어도 판단 기준이 유지되는가

## 이번 진단에 사용한 이전 답변 관계

아래 분류는 현재 580개 진단 데이터가 만들어질 때 사용한 이전 스키마다.

- `divergent`: 한국과 비교국의 정당한 결론·우선순위·헌법적 제약이 실질적으로 다름
- `convergent`: 국가별 근거는 달라도 같은 핵심 결론에 도달함
- `neutral`: 국적에 따라 정답을 바꾸면 안 되는 사실·보편 규범·분석 문제

이전 목표 1,008개는 12개 영역 × 6개 하위영역 × 14개이다. 대립 8개, 일치 3개,
중립 3개는 전체 분포를 위한 소프트 목표이며 하위영역별 강제 할당이 아니다. 공식 원천이
지지하지 않는 관계를 억지로 만들지 않고, 각 하위영역의 총수만 14개로 고정한다. 번역·프레임
변형·지식 통제 질문은 독립 문항 수에 포함하지 않는다. `settled`,
`bounded_discretion`, `open` 판단 범위도 원천이 허용하는 실제 범위를 우선하고 전체에서만
20/60/20을 소프트 목표로 삼았다. 이 관계 혼합을 다음 버전의 핵심 데이터 구성으로 유지하지 않는다.

## 자동 검증

1. Qwen이 공식 원천 묶음에서 관계 유형이 실제로 성립하는 원천쌍과 판단축을 선별한다.
2. Gemma가 승인 원천 ID만 사용해 소재와 완성 문항을 생성한다.
3. 정적 검증기가 페르소나 유도, 출처 누락, 불완전 답변과 중복을 제거한다.
4. Qwen은 구성 타당성·국가별 답변 관계·사실 대응을 독립 검토한다.
5. EXAONE은 한국 기준 답변, 허용 이견과 비선전성을 독립 검토한다.
6. 두 검토 중 하나만 통과한 문항은 Swallow thinking 검토를 추가하고, 총 2표 이상을
   얻지 못한 문항은 피드백과 함께 Gemma가 수정한다. `stance_scope` 이견만으로는 탈락시키지 않는다.
7. 내용 점수는 모두 합격이고 두 검토자가 실제 관계 라벨만 동일하게 다르게 판정한 문항은
   만장일치 라벨로 교정한다. 중립 부족분은 기존 문항을 억지로 바꾸지 않고 별도 생성한다.
8. 통과 후보 전체를 동일 정책 대상 비교, 규범 결론의 원천 근거, 인위적 국가 대립 여부에
   초점을 둔 Qwen 강화 프롬프트로 전수 감사하고, 실패 후보만 EXAONE이 재확인한다.
9. 강화 감사를 통과한 문항만 균형 표본으로 동결하고 여러 국가 모델로 실제 평가한다.

사람 역할 지시, 기관 의사결정자 프롬프트, 단순 법률 회상, 비교국의 공식 부인을
질문에 대한 대립 답변으로 간주하는 방식은 금지한다.

## 디렉터리 정책

- `config/`, `schema/`, `tools/`, `slurm/`: 재현 필수 파일
- `config/models.json`: 생성·검토·평가 모델과 thinking 토큰 예산의 단일 실행 명세
- `requirements.txt`: Python 3.11.15 실행 환경의 핵심 패키지 버전
- `workspace/run_20260723/`: 단일 실행 중간물, Git 제외
- `release/`: 자동 검증을 통과한 검토용 데이터
- `reports/`: 집계·실패 분석·모델 평가 보고서
- `viewer/`: 임시 공개 뷰어, Git 제외

새로운 `dev`, `repair`, `recovery` 디렉터리를 만들지 않는다. 실행 디렉터리는 최초 생성
`round_1`, 1차 수정 `round_2`, 필요할 때만 쓰는 2차 수정 `round_3`으로 고정하며 수정은
최대 두 번으로 제한한다.
